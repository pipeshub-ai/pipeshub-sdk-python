# GetKnowledgeHubChildNodesSortBy

Field to sort results by. Omitted → default `updatedAt`.
Unknown value → silently falls back to `name`.



## Values

| Name         | Value        |
| ------------ | ------------ |
| `NAME`       | name         |
| `CREATED_AT` | createdAt    |
| `UPDATED_AT` | updatedAt    |
| `SIZE`       | size         |
| `TYPE`       | type         |
