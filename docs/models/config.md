# Config

Value of any other auth field the connector type declares, keyed by the field's `name`


## Supported Types

### `str`

```python
value: str = /* values here */
```

### `bool`

```python
value: bool = /* values here */
```

### `float`

```python
value: float = /* values here */
```

### `List[str]`

```python
value: List[str] = /* values here */
```
