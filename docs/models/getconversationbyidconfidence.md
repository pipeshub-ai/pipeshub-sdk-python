# GetConversationByIDConfidence

AI confidence in the answer. Present only on `bot_response` messages, and only when the model emitted a trailing confidence block.


## Values

| Name        | Value       |
| ----------- | ----------- |
| `VERY_HIGH` | Very High   |
| `HIGH`      | High        |
| `MEDIUM`    | Medium      |
| `LOW`       | Low         |
| `UNKNOWN`   | Unknown     |
