# NavigateKnowledgeGraphResponseSchema

Response returned by GET /connectors/navigate.

Field names are snake_case, matching the knowledge graph's internal
view models. `text` carries the same flat-text rendering PipesHub's
own agent sees for this node; the remaining fields carry the same
information in structured form.
